# Installation & Setup Guide
### Via PyPI
Execute:
```
pip install valediction
```

### Via GitHub (`uv`)
To install in development mode, we recommend using uv.

1) Install uv from the [Astral website](https://docs.astral.sh/uv/getting-started/installation/), or install via PyPI with `pip install uv`

2) Clone the Valediction repo:
```
git clone https://github.com/SETT-Centre-Data-and-AI/Valediction.git
```

3) Navigate to the repositry (`cd ...\Valediction\`) and execute:
```
uv sync --group dev
```

### Via GitHub (`poetry`)
1) To install in development mode with poetry:
```
pip install poetry
```

2) Clone the repo:
```
git clone https://github.com/SETT-Centre-Data-and-AI/Valediction.git
```

3) Navigate to the repositry (`cd ...\Valediction\`) and execute:
```
poetry install
```
